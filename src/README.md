# src/

The project's importable Python code. Anything under here is meant to be used from other code (`from sdg.pinned import pinned`) rather than run by hand; the hand-run tools live in `scripts/`, and the checks that prove this code works live in `tests/`.

It is installed once, from the repo root, with `pip install -e .` (README.md, step 1b). The `-e` means editable: Python runs the files where they sit here, so an edit takes effect with no reinstall, and the package can find `data/` and `scripts/` relative to itself. Installed without `-e`, the code would be copied into Python's own library folder and could find neither; `sdg.pinned.require_repo()` detects that and says so.

| Folder | What it is |
| --- | --- |
| `sdg/` | The package itself. Its own `README.md` lists every module. |
| `sdg.egg-info/` | Generated by `pip install -e .`: a few small text files (name, version, file list) that tell Python the package `sdg` is installed and where. Not source, not committed (`.gitignore` excludes `*.egg-info/`), safe to delete; the next `pip install -e .` recreates it. The "egg" is an old name for a Python package format, kept by the tooling. |

Which script or module calls which: `docs/code_map.md`.
