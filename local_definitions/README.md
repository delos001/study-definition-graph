# local_definitions/

This folder holds definitions this project adds to a published standard.

Everything in this folder is in draft. The structure may be realigned substantially when the prompt axes are worked out in issue #15, so no validation is built for it until the structure is stable. Issue #32 tracks that validation.

A definition belongs here when the project needs something a standard does not support, and writes it down so that the pipeline and a reader can both interpret it.

CDISC and the other publishers have not endorsed anything in this folder.

The files are written here and committed to git. They are not pinned, so the rules for `inputs/` do not apply to them.

| Folder | What it holds |
| --- | --- |
| `usdm_extensions/` | The fields this project adds to USDM through the standard's extension mechanism. |
