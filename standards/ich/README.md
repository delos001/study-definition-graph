# standards/ich/

Guidelines published by the International Council for Harmonisation (ICH).

| Item | What it is |
| --- | --- |
| `m11_step4/` | ICH M11, the structured protocol template, at Step 4 (adopted 2025-11-19). Three documents: the template, the technical specification of its data elements, and the short guideline on scope. |
| `e9r1/` | ICH E9(R1), the addendum defining an estimand and its parts. One document. |

One folder per guideline, named with its version, whatever the file count; a folder's location must not change when a second document is added to it. Files keep ICH's own names, which carry the step and the adoption date.
