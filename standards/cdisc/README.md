# standards/cdisc/

Standards published by CDISC.

| Folder | What it holds |
| --- | --- |
| `usdm_v4/` | The Unified Study Definitions Model, version 4.0: the model files the code reads (data structure, data dictionary), the legal values and conformance rules, the implementation guide, the API schema, and a `uml/` subfolder with the hand-authored master and its class diagrams. |
| `biomedical_concepts/` | The Biomedical Concepts library: standardized definitions of clinical measurements that a USDM activity can point at, with its field guide and an overview. |

Crosswalks CDISC has written to other systems are in `../crosswalks/`, alongside any from other authors.
