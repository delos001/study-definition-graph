# USDM local extensions

Every field this project adds to USDM, and why the standard had no place for it.

USDM has a field for most of what a clinical document says. Where it does not, the standard's own escape hatch, the extension mechanism in IG 6.4, lets a field be attached anyway. A field attached that way is invented here, so nobody outside this project can interpret it unless it is written down. That is what this file is for. An extension is kept for the life of the project once it exists, so each one is a commitment rather than a note.

Nothing has been added yet. The first entries arrive with the extraction work in Phase 3 of `PLAN.md`.
