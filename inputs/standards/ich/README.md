# inputs/standards/ich/

This folder holds the guidelines the International Council for Harmonisation (ICH) publishes.

| Item | What it is |
| --- | --- |
| `m11_step4/` | ICH M11, the structured protocol template, at Step 4 (adopted 2025-11-19). The documents are the template, the technical specification of its data elements, and the short guideline on scope. |
| `e9r1/` | ICH E9(R1), the addendum defining an estimand and its parts. |

Each guideline has one folder, named with its version, whatever the file count. A folder's location must not change when a second document is added to it. Files keep ICH's own names, which carry the step and the adoption date.
